# SOMSTART Maths Whiteboard

A React, TanStack Start, Vite, and Tailwind application for mathematics practice. The whiteboard includes a TI-30XS-style calculator, graphing tools, a formula sheet, customizable board backgrounds, and browser-based handwriting recognition powered by Tesseract.js.

## Development

Requirements: Node.js 24 or later and npm.

```sh
npm install
npm run dev
```

## Validation and deployment

```sh
npm test
npm run build
```

The application is configured to build with Nitro's Vercel preset. Import this repository into Vercel and use `npm run build` as the build command.
