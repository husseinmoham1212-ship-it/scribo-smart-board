# Math Canvas Pro

build a complete whiteboard with the following 
-TI-30XS multiview calculator in form of a small button on side side of whiteboard
-text both for typing questions
-white working area for the maths problem
-all features of GED maths concepts , including graph displayed when wanted
- autocorrection functionality( like when a teacher/instructor writes the solution with stylus or finger tip) the board changes the written to normal computer text immediately as writing continues
-changeable background color
